<h1> Text Styling Playground</h1>

<p>
    <strong>Text Styling Playground</strong> is a simple, interactive front-end project built using 
    <code>HTML</code>, <code>CSS</code>, and <code>JavaScript</code>.  
    It allows users to type custom text and experiment with different styling features such as 
    color changes, font modifications, background highlights, and theme switching.
  </p>

 <h2>🚀 Features</h2>
  <ul>
    <li>👉 Enter any text and display it dynamically.</li>
    <li>🎨 <strong>Color Change:</strong> Toggle between default and blue text color.</li>
    <li>🔠 <strong>Font Size Change:</strong> Increase or decrease the text size.</li>
    <li>🖋️ <strong>Font Family Change:</strong> Switch between font families.</li>
    <li>🟦 <strong>Background Highlight:</strong> Add or remove background color for the text.</li>
    <li>🌙 <strong>Dark/Light Mode:</strong> Toggle between themes for the entire page.</li>
    <li>🔄 <strong>Reset:</strong> Clear text and remove all applied styles instantly.</li>
  </ul>

  <h2>🛠️ Tech Stack</h2>
  <div class="highlight">
    <ul>
      <li><b>HTML5</b> – for structure</li>
      <li><b>CSS3</b> – for styling and transitions</li>
      <li><b>JavaScript </b> – for DOM manipulation and interactivity</li>
    </ul>
  </div>

  <h2>📂 Project Structure</h2>
  <ul>
    <li><code>index.html</code> – Main page layout</li>
    <li><code>sp.css</code> – Styling file for themes, text, and buttons</li>
    <li><code>SP.js</code> – JavaScript file handling events and toggling styles</li>
  </ul>

  <h2>⚡ How It Works</h2>
  <ol>
    <li>User types text into the input box and clicks <b>Enter</b>.</li>
    <li>The text appears in the paragraph section.</li>
    <li>Style buttons allow toggling of color, font size, family, and background.</li>
    <li>The theme button switches between light and dark mode with smooth transitions.</li>
    <li>The reset button clears text and restores everything to default.</li>
  </ol>
